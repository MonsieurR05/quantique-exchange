# UG Software Engineering Project

## Setup

1. Install dependencies:
   npm install

2. Make a .env file and add the following: API_TOKEN= and BASE_URL= .   
   The key and url can be found on Moodle.

3. Start the server:
   node run.js

4. Open in browser:
   http://localhost:3001
