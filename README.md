# UG Software Engineering Project

## Setup

1. Install dependencies:
   npm install

2. Add to the env file: 

   2.1 API_TOKEN=
   
   2.2 BASE_URL=

3. Start the server:
   node server.js

4. Open in browser:
   http://localhost:3001
