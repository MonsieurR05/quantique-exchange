# User Feedback and Actions

| User Feedback | Decision | Action Taken / Planned | Reason |
|---|---|---|---|
| Trading panel was too small | Implemented | Expanded and clarified the trading panel | BUY/SELL actions and signals are core to the prototype |
| Graphs did not clearly feel live | Implemented | Added live status, last updated time, and refresh count | Users needed visible proof that data was refreshing |
| Default sensor values looked like only 0 and 1 | Implemented | Prioritised smoother non-binary sensors where available | Binary charts looked confusing for beginner users |
| Raw sensor names were hard to understand | Implemented | Added company-style asset names with sensor IDs in brackets | Improves beginner understanding while keeping transparency |
| Tutorial/help menu suggested | Planned / deferred | Beginner guide planned for Sprint 2 | Useful, but not required before core prototype stability |
| Pinned balance changing in real time | Partially implemented | Added simulated balance and owned shares | Supports trading simulation without building a full portfolio system |
| More advanced money simulation | Deferred | Kept simple BUY/SELL and balance logic | Avoids over-scoping before MVP completion |
